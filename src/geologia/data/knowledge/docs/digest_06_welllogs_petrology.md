# سجلات الآبار والبترولوجيا

سجلات الآبار (Well Logs) تُقرأ من ثلاثة مراجع متدرجة: دليل Asquith وGibson (1982) تمهيداً، ودليل Rider (2002) بعين الجيولوجي، ودليل Schlumberger الكلاسيكي (1989) كممارسة صناعية موحدة — وهي الكتب التي تُبرر قاعدة المنصة: أي قراءة منحنى LAS تمر أولاً بالتحقق الصيغ (NULL، وحدات، منحنيات معلنة) قبل أي تفسير.

الصيغة LAS نفسها موثقة في توثيق lasio (lasio.readthedocs.io) وstriplog للطبقات؛ والمدقق الصيغي المدمج في المنصة يفحص إصدار LAS ووجود NULL وتناسق STRT/STOP/STEP مع عدد صفوف البيانات — فكل ملف لا يجتاز الفحص لا يدخل أي تحليل.

البتروجرافيا المكملة: وِنتر (2010) للصخور النارية والمتحولة، وبِغز (2006) ورِيدنغ (1996) للرسوبيات والطباقية — أساس قراءة القطاعات الترسية.

المصادر المؤسِّسة في الكتالوج: manual-asquith-1982، manual-rider-2002، manual-slb-loginterp، classic-winter-2010، classic-boggs-2006، classic-reading-1996.
