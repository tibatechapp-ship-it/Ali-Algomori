# النمذجة ثلاثية الأبعاد وعدم اليقين

النمذجة الجيولوجية ثلاثية الأبعاد الحديثة قامت على مدارس أسترالية وأوروبية: GemPy (مفتوح، CGRE Aachen) للنمذجة الضمنية الاحتمالية، وLoopStructural ومسار Loop (map2loop تحويل الخرائط إلى مدخلات) للنمذجة البنيوية، وNoddy/pynoddy التعليمي للتاريخ البنيوي، وcurlew للحقول العصبية البحثية وRGM للنماذج الاصطناعية.

قاعدة الصدق الرقمية للمنصة: نموذج GemPy بخمس نقاط تحكم يُستخدم لعرض بنية الطبقات العامة ونطاق عدم اليقين في نطاق صغير موثق — وليس لقراءة أعماق دقيقة لقرارات حفر أو هندسة. عدم اليقين ليس ملحقاً بل مخرج أساسي يُعلن مع كل نموذج، وفق منهج الفرضيات المتعددة (شامبرلين 1897) الذي تعتمده بوابات المنصة.

المصادر المؤسِّسة في الكتالوج: بطاقات المحركات gempy وloopstructural وmap2loop وnoddy وcurlew وrgm في قاعدة معرفة المحركات، مع classic-chamberlin-1897 وclassic-twiss-moores-2007 كخلفية.
