# الجيوكيمياء والخامات المعدنية

الجيوكيمياء الحديثة قامت على أساس جولدشمِت الكمي (1954) لتوزيع العناصر، وتُمارس عملياً عبر ثلاثة كتب: رولينسون (1993) لقراءة البيانات وعرضها وتفسيرها — وهو الأقرب لمسار Geochemistry π — وفَور (1986) وديكن (2018) للأيزوتوبات.

قاعدة المنصة الجيوكيميائية: أي تصنيف صخري بتعلم الآلة يبدأ من بيانات مُقاسة بمرجع معياري (standard reference material) موثق، والنتيجة تُعرض بفئات احتمالية لا بحقائق قاطعة. وخرائط قابلية الاستكشاف (EIS Toolkit) تُرتب أولويات مسح ميداني فقط ولا تؤكد وجود معدن — حد صلاحية ثابت.

جيولوجيا الخامات تُقرأ من جيلبرت وبارك (1986) شمولاً، مع بوابات أبحاث أمريكية وبريطانية (AAPG للبترول، SEG للجيوفيزياء المستكشفة، GSA) ومنشورات المسوح الوطنية العربية (السعودية SGS، مصر EGSMA، اليمن YGSMRB ورقياً).

المصادر المؤسِّسة في الكتالوج: classic-goldschmidt-1954، classic-rollinson-1993، classic-faure-1986، classic-dickin-2018، classic-guilbert-park-1986، portal-saudi-sgs، portal-egypt-egsma، portal-yemen-ygsmrb.
