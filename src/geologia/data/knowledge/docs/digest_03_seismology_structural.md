# الزلازل والجيولوجيا البنيوية

علم الزلازل الكمي يُقرأ من آكي وريتشاردز (1980) كأساس رياضي، مع شييرر (1999) وشتاين وويسِشن (2003) كمداخل معاصرة. وصلت الزلازل إلى تكتونية الصفائح عبر ورقة إيزاكس وأوليفر وسيكس (1968) التي ربطت توزيع الزلازل بحدود الصفائح — وهو الأساس النظري لاستخدام ObsPy وPyrocko وOpenQuake في الخطة.

قاعدة الخطر الزلزالي الموثقة: حساب PSHA عبر OpenQuake بمصادر مبسطة ومخزون افتراضي مقبول لفهم «الترتيب النسبي للخطر بين مناطق» فقط، وليس لمعايير تصميم مبانٍ أو تأمين — هذا حد صلاحية مكتوب لا يتغير.

الجيولوجيا البنيوية — الطيات والفوالق — تُقرأ من بيلينجز (1972) كلاسيكياً، وتويس وموريس (2007) وديفيس وريينولدز (2011) معاصرة، وهي الخلفية المطلوبة للنمذجة ثلاثية الأبعاد (GemPy وLoopStructural) قبل الأسبوع 5.

المصادر المؤسِّسة في الكتالوج: classic-aki-richards-1980، classic-shearer-1999، classic-stein-wysession-2003، classic-isacks-1968، classic-billings-1972، classic-twiss-moores-2007، classic-davis-reynolds-2011.
