# ADR-0001: وكيل رئيسي واحد + محركات علمية معزولة

- الحالة: مقبول
- التاريخ: 2026-11-21

## السياق

نريد منصة جيولوجية ثنائية اللغة تنسّق أدوات علمية ممتازة موجودة أصلًا
(QGIS، GemPy، MODFLOW 6، ObsPy ...) دون إعادة كتابتها، وبموارد محدودة في البداية.

## القرار

1. وكيل رئيسي واحد («المهندس الجمهوري») يقود التخطيط والتنسيق والتحقق.
2. الوكلاء المتخصصون **أدوار داخل النظام** وليسوا 8 نماذج ذكاء اصطناعي منفصلة.
3. كل محرك علمي يعمل في بيئة معزولة خلف Adapter بعقد موحد عبر سجل مركزي.
4. لا تُدمج أي أداة قبل التحقق من رخصتها وإصدارها واختبارها المرجعي.

## البدائل المرفوضة

- بيئة Python واحدة لكل الأدوات: تعارض GDAL/NumPy/Qt/PyTorch يجعل كل تحديث خطرًا.
- نموذج ذكاء اصطناعي مستقل لكل تخصص: كلفة موارد بلا داعٍ في هذه المرحلة.
- إعادة كتابة قدرات GIS من الصفر: هدر؛ QGIS وأدوات المجتمع ناضجة ومختبرة.

## العواقب

- تعقيد تشغيلي أعلى (عوّضناه بسجل محركات وعقود موحدة) مقابل أمان وتحديث مستقل.
- واجهة الوكيل موحدة، فإضافة محرك لاحقًا لا تمس النواة.
