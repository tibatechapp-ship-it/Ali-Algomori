# GEOLOGIA Academy — المسار التعليمي العملي

**A practical learning track bound to real, working tools — every lab below runs
on the current CLI today, not on a promise.**

> القاعدة: لا مخبر نظري. كل مستوى يُتدرب فيه على أدوات تعمل فعلاً في
> الإصدار الحالي، ويُقيَّم بمجموعة الاختبارات الذهبية المجمدة (T3) — نفس
> الأداة التي تُقيّم بها Ali نفسها. المسار مربوط بالقدرات الحقيقية لـ v0.8.1
> ويتوسع مع كل مرحلة تُفتح في [خارطة الطريق](ROADMAP.md).

## المستوى 1 — الأصول الصادقة (مبتدئ)

**من هو؟** طالب سنة أولى/ثانية جيولوجيا أو علوم أرض، أو معلم مدرسة.

**مخرجات التعلم:** فهم تصنيف الصدق الثلاثي (موثق/استنتاجي/غير قابل للتأكيد)،
المجالات التسعة، معرفة أين تبحث وأين يُرفض السؤال.

**المخبر العملي (يعمل الآن):**
```bash
geologia about                          # لماذا المنصة قيد الإنشاء وما حقوقها
geologia domains                        # المجالات التسعة المدعومة
geologia knowledge search "ما هو الشيلم؟" --top-k 3
geologia knowledge search "أسعار الذهب اليوم"   # ← لا مجال: رفض صادق
```
**الدرس المفصلي:** سؤال خارج المكتبة لا يجيب بلا مكتبة — هذا ليس ضعفاً بل
عقد صدق.

## المستوى 2 — البيانات الصادقة (متوسط)

**من هو؟** طالب متقدم/مساعد باحث.

**مخرجات التعلم:** لماذا CRS والوحدات المعلنة تُفحص مقابل المحتوى الفعلي،
ما معنى provenance مضاد للتلاعب، وكيف يُرفض ملف مزيف.

**المخبر العملي (يعمل الآن):**
```bash
geologia verify tests/data/golden_las_valid.las --type las     # ناجح
geologia verify tests/data/golden_las_truncated.las --type las # مبتور: يُرفض بالسبب
geologia dataset add "بئر تدريب" tests/data/golden_las_valid.las --dtype las
geologia dataset validate <dataset_id>
geologia dataset checksum <dataset_id>                          # بصمة تُفحص لاحقاً
```
**الدرس المفصلي:** كل بايت له مصدر وبصمة؛ إعلان البيانات عن نفسها ليس
حجيته — المحتوى الفعلي هو الحَكم.

## المستوى 3 — المحركات المعتمدة (متقدم)

**من هو؟** باحث/مهندس مبتدئ.

**مخرجات التعلم:** دورة حياة المحرك المعتمد كاملة: بوابة البدائل، مرور
البنى، التنفيذ مع كشف العبث، وقراءة تقرير الأدلة (المدخلات، الاستشهادات،
±1σ، حدود الصلاحية).

**المخبر العملي (يعمل الآن):**
```bash
geologia engines --domain petrology
geologia task create "مسامية بئر تدريب" porosity_density_v1 <dataset_id> --param rho_ma_gcm3=2.65
geologia task go <task_id> inputs_validated && geologia task go <task_id> ready
geologia task execute <task_id>
geologia task report <task_id>
```
**الدرس المفصلي:** محرك بلا مرجع مثبت لا يُنفذ — والامتياز الأكاديمي هنا
أن الطالب يرى بالعين كيف يُرفض المحرك غير المعتمد قبل أن يرى كيف يعمل
المعتمد.

## المستوى 4 — الإشراف وبناء المعرفة (باحث/مُشرف)

**من هو؟** ماجستير/دكتوراه، عضو هيئة تدريس، موظف مسح أو شركة.

**مخرجات التعلم:** بناء وحدة معرفة مرخصة وفق مخطط v1، تصميم أسئلة ذهبية
وسلبية لمجال تخصصي، قراءة ADRs كمنهجية قرارات معمارية، وتقييم جودة أدلة
من طرف ثالث.

**المخبر العملي (يعمل الآن):**
```bash
# وحدة معرفة بمخطط v1 (claim، مصدر، DOI، ثقة، مراجعة، رخصة):
python -c "from geologia.knowledge.units import KnowledgeUnit; print(list(KnowledgeUnit.__fields__.keys()))"
# التدقيق الحتمي للمجموعة الذهبية:
python -m geologia.evaluation.audit
# قراءة منهجية القرارات:
# docs/adr/0001 → docs/adr/0008 (وحدكم بأفضلية: القرار ثم البدائل المرفوضة ثم العواقب)
```
**الدرس المفصلي:** من يعلم الآلة يجب أن يعرف كيف تُقيَّم — designing golden
questions هو أصعب وأشرف عمل في المشروع، والمشروع يعترف به عملياً (بطاقات
الوكلاء التسعة).

## التقييم والاعتماد الأكاديمي

- كل مستوى يُختتم بمجموعة أسئلة من ملف التقييم المجمد
  (`src/geologia/data/evaluation/golden_eval_v1.json`) — القسم الذهبي
  للقدرات، والقسم السلبي لكشف الثقة الزائفة، والمراجع المزيفة لترييض
  الطالب على اكتشاف الاستشهاد الضعيف.
- الجامعة الشريكة تُصدر «شهادة اجتياز مستوى» بعد التحقق محلياً — لا
  شهادة صادرة عن وعد، بل عن تشغيل فعلي اجتاز بوابات قابلة لإعادة
  الإنتاج في أي مكان.

## ماذا يصبح المتخرج من المسار؟

مستوى 1–2: مستخدم بيانات صادق (أي مكتب فني). مستوى 3: مشغّل مهام معتمدة
(مركز مسح، شركة مياه/تعدين). مستوى 4: باني معرفة ومُقيِّم (جامعة، مركز
أبحاث) — وكلها أدوار يحتاجها العالم العربي في هذا القطاع بالآلاف،
والمنصة تدرب عليها بلغته.
