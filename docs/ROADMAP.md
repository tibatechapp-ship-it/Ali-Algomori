# خارطة الطريق

التقدم محكوم ببوابات قبول، ليس بمرور الوقت.

| المرحلة | المحتوى | بوابة القبول |
| ------- | ------- | ------------ |
| 0 — التأسيس | مستودع + وثائق + CI + نواة API | CI أخضر على المسارين + اختبارات ناجحة |
| 1 — النواة | مشاريع، سجل بيانات، سجل مهام دائم، سجل أدوات | مهمة تُسجّل وتُستعاد بعد إعادة تشغيل |
| 1.5 — البيانات الموثوقة (بدأت في 0.3.0، اكتمل مسار الاعتماد في 0.4.0) | طبقة تحقق البيانات بمدخلات ونتائج مرجعية ذهبية + سجل مهام ببوابات إلزامية وعزل + طبقة معرفة استرجاعية بلا هلوسة + **مسار اعتماد `certified` بأول محرك علمي أول-الطرف موثق وتقرير تنفيذ بالأدلة وحدود عدم اليقين** | تسجيل مجموعة حقيقية + تحقق بصمة ومدقق صيغة بنيوي + رفض التنفيذ قبل `certified` مُختبر + معرفة تجيب باستشهاد أو «ليس في المكتبة» + **محرك معتمد يُنفذ فقط بعد مرجع مثبت وكشف عبث لحظة التنفيذ** |
| 2 — GIS حقيقي | GeoJSON/GeoPackage/GeoTIFF، اكتشاف CRS، خريطة تفاعلية، GeoPandas/Rasterio، QGIS/GRASS عبر Workers | رفع ملف حقيقي + اكتشاف CRS صحيح + تحليل مكاني مطابق لمرجع |
| 3 — أول وكيل | فهم الطلب، بيانات ناقصة، خطة، استدعاء أدوات GIS، أدلة | تقرير قابل للتتبع من البداية للنهاية + رفض صحيح عند نقص البيانات |
| 4 — النمذجة 3D | GemPy ثم LoopStructural/map2loop، وcurlew كتجربة بحثية | نموذج مرجعي قابل لإعادة الإنتاج + عدم يقين معلن |
| 5 — المياه الجوفية | بيانات آبار، MODFLOW 6، Pastas، سيناريوهات ضخ/تغذية | معايرة مستقلة + تقرير حساسية — وإلا لا توصية |
| 6 — الجيوفيزياء والزلازل | ObsPy، SimPEG، PyGIMLi، OpenQuake، SeisComP لاحقًا | عكس/خطر مطابق لاختبار مرجعي موثق |
| 7 — التنقيب والاستشعار | EIS Toolkit، GeoPyTool، OpenDroneMap، Geochemistry π، RGM/Bedrock-ge حسب الجاهزية | خرائط قابلية موسومة بحدود الثقة + منتجات فوتوغرامترية مفحوصة |
| 8 — بيانات اليمن | فهرسة خرائط هيئة المسح الجيولوجي، إسناد جغرافي، DEM واستشعار | ترخيص كل خريطة متحقق قبل التوزيع + مثال قابل لإعادة الإنتاج |

**قاعدة مالك المنصة الملزمة (2026-11-21):** المرحلتان 2 وما بعدها مقفلتان خلف
المرحلة 1.5 — لن يبدأ دمج GemPy أو MODFLOW أو أي محرك قبل اكتمال طبقة البيانات
الموثوقة واختباراتها المرجعية، وراجع [معيار القبول الملزم](ACCEPTANCE_STANDARD.md).

## إصدار 0.1 (MVP علمي)

واجهة عربية/إنجليزية حقيقية · مشاريع وملفات · خريطة تفاعلية · تحليل GeoPandas ·
فحص Raster بـ Rasterio · المهندس الجمهوري مع سجل أدوات · تقارير قابلة للتتبع · اختبارات.
لا يُعلن عن عدد محركات مدمجة إلا بعد اجتياز كل محرك بوابة `certified`.
