# حوكمة البيانات

1. **الخام غير قابل للتعديل**: الملفات الأصلية تُحفظ كما هي (checksum عند الاستلام)،
   وأي معالجة تُنتج ملفات مشتقة منفصلة مرتبطة بالأصل (`derived_from`).
2. **CRS والوحدات إلزاميان**: لا تحليل بدون نظام إحداثيات معروف ووحدات موثقة؛
   التحويل يُسجّل كخطوة provenance مستقلة.
3. **حقول provenance لكل مجموعة بيانات**: المصدر، الرابط/الجهة، الرخصة وشروط الوصول،
   تاريخ الاستلام، CRS، الوحدات، checksum، سلسلة الاشتقاق.
4. **حزمة بيانات اليمن**: البدء بفهرس خرائط هيئة المسح الجيولوجي والثروات المعدنية
   (مقاييس وأنواع مختلفة)؛ **التحقق من شروط الوصول والترخيص لكل خريطة قبل توزيعها**
   داخل التطبيق أو المستودع. الخرائط الورقية تحتاج إسنادًا جغرافيًا موثق الخطأ.
5. **الخصوصية**: مواقع الآبار والمنشآت قد تكون حساسة؛ صلاحيات وصول على مستوى المشروع،
   ولا نشر عام لبيانات مستخدم دون إذنه.
6. **الاحتفاظ**: سجل مهام وتدقيق دائم (من، ماذا، بأي بيانات، بأي إصدار، وما النتيجة).
